# Диплом: автономное судовождение в узкостях

Тема: «Исследование и анализ применения технологий автономного судовождения (MASS) при плавании в узкостях и перспективы их внедрения на морском флоте».

В 1.2 раскрыто понятие узкости, в 1.3 — устройство автономной системы: датчики, обработка наблюдений, оценка опасности, выбор движения, авторулевой и обратная связь. Содержание включает все четыре запланированные главы. Номера страниц есть у написанных частей; будущие пункты оставлены без номеров и служебных отметок. Работа ещё не завершена.

Материалы готовятся с Academic Research Suite и проверкой источников. Россия рассматривается первой, затем японский опыт; один район планируется как пример в конце работы. Главный вопрос технического анализа — обнаружение опасности и понимание обстановки.
