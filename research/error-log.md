# Журнал ошибок

Перед каждым содержательным этапом прочитать этот файл. Добавлять запись после обнаружения реальной ошибки; после исправления указывать способ проверки. Не превращать журнал в перечень придуманных промахов. Расхождения внешних источников отражать отдельно в заметках об источниках.

## E001 — Способ передачи файлов оказался недоступен пользователю

- Обнаружено: 09.10.2026, по сообщению пользователя.
- Ошибка в организации работы: предыдущие результаты передавались ссылками на локальные файлы, которые пользователь не мог скачать. Наличие файла в среде не обеспечило получение результата.
- Исправление: основной способ доставки — Word и сопутствующие материалы в GitHub `nikitakozyr51-wq/diplom-moi`. Пользователь явно разрешил публикацию.
- Проверка: первая отправка — коммит `876321a`. Удалённая ветка `main` совпала с коммитом; оба Word скачаны с GitHub с HTTP 200 и совпадением SHA-256 с локальными файлами. Для каждого обновления повторять проверку доставки.
- Предотвращение: в ответах давать ссылки GitHub; основной актуальный файл обозначать в README.

## E002 — Структурная проверка PDF выполнена после первого использования страниц

- Обнаружено и исправлено: 09.10.2026.
- Ошибка процесса: для ранних нормативных PDF сначала использованы ссылки на страницы, а проверка `pdf_read_preflight.py`, предусмотренная ARS, выполнена позднее.
- Исправление: выполнена проверка всех четырёх нормативных PDF и семи новых учебных файлов. Все 11 получили `PASS`; отчёты сохранены в `literature/pdf-preflight/`.
- Граница проверки: `PASS` проверяет структуру и подсчёт страниц. Он не подтверждает фактическую истинность текста, авторство, актуальность документа или точность формул.
- Предотвращение: для каждого нового PDF до доверия к страничным ссылкам выполнить preflight, затем прочитать нужный фрагмент. Записывать `UNAVAILABLE` и `FAIL` как полученные результаты, не подменять их успехом.

## E003 — Экспортёр по умолчанию выбирал устаревший фрагмент

- Обнаружено и исправлено: 09.10.2026.
- Ошибка инструмента: `tools/export-draft.py` по умолчанию собирал первый фрагмент 1.1–1.2, хотя основным файлом уже стал `drafts/working-draft.md`. Описание скрипта также говорило только о первых двух подразделах.
- Исправление: основной вход и выход по умолчанию заменены на `working-draft.md` и `working-draft.docx`; описание уточнено. Явные параметры для отдельной главы сохранены.
- Проверка: запуск без параметров должен обновлять общий Word; структурная проверка сравнивает его заголовки и ссылки с текущим Markdown.
- Предотвращение: при смене основного документа синхронизировать README, инструкции и значения по умолчанию.

## E004 — Неудачная попытка применить текстовый патч

- Обнаружено и исправлено: 09.10.2026.
- Ошибка: при дополнении 1.2 в патче использована только начальная часть строки, хотя абзац в Markdown хранится одной длинной строкой. `apply_patch` отклонил весь патч, включая изменение экспортёра.
- Исправление: проверено фактическое состояние обоих файлов; изменения выполнены повторно с точным совпадением строк.
- Проверка: после отказа правки отсутствовали; после корректного патча появились новые абзацы и новые значения по умолчанию. Word проверяется после сборки.
- Предотвращение: читать точный контекст перед заменой; ошибка инструмента не означает частичный успех. После отказа проверить состояние, прежде чем повторять или сообщать об исправлении.

При последующей полной замене заметок ещё один патч был отклонён из-за двух операций над одним путём. Изменения не считались выполненными; замена сделана одной записью файла. При составлении патча использовать одну операцию на каждый путь.

## E005 — В плане оставалась уже пройденная повестка

- Обнаружено и исправлено: 09.10.2026, при проверке по ARS.
- Ошибка документации: `plan.md` продолжал предлагать первоначальные вопросы об уровне обучения, главной проблеме и знакомом районе после полученных ответов. Формулировка о согласовании метода до написания любого основного текста также не соответствовала текущей стадии.
- Исправление: раздел повестки заменён текущими решениями и открытыми сведениями; согласование отнесено к методу и выполнению практической части. Связи задач, разделов и источников вынесены в таблицу.
- Проверка: ответы сохранены в `project-context.md`, план не требует повторного интервью или остановки теоретической работы.
- Предотвращение: при переходе этапа сверять план с контекстом и текущими файлами; различать подготовку теории и утверждение метода практической части.

## E006 — Две выдержки не находились в сохранённом извлечении PDF

- Обнаружено и исправлено: 09.10.2026, проверкой `tools/check-draft.py`.
- Ошибка реестра: выдержки C038 и C039 были набраны с восстановлением цельного слова, тогда как извлечение PDF содержало внутренние пробелы в словах. Поэтому их точное нахождение в указанном фрагменте не подтверждалось автоматически.
- Исправление: выдержки заменены на короткие дословные фрагменты тех же страниц. Смысл утверждений и текст диплома не менялись; проверка не ослаблена.
- Проверка: все восемь новых выдержек обнаружены на указанных страницах. Проверка Word, ссылок, источников и контрольных сумм получила `passed`.
- Предотвращение: копировать опорную выдержку из сохранённого извлечения и сверять с PDF; объяснение своими словами хранить отдельно. Ошибки извлечения не исправлять незаметно внутри поля дословной выдержки.
